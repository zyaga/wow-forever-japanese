- **NPC が自分の声で話します。** 話し手が分からないクエストの行は、NPC の種族や性別に関係なく、ナレーター（年配のタウレンの男性）の声で読まれていました。これからは、その行を話す NPC の声で読み上げます。
- **間違った声より無音。** NPC がまだ分からない行や、音声がまだできていない行は読み上げません。これまで音声があった行の一部は、次の音声パックのリリースまで無音になります。
- **ウィンドウに表示されます。** 音声パックを入れていると、音声がまだない翻訳済みの行に `[音声なし / No Voice Yet]` と表示されます。「音声」ページの設定でこの表示を消せます。
- **英語テキスト収集が声探しを手伝います。** クエストウィンドウを開くたびに、その NPC の数値 3 つ（ID、性別、モデル ID）も記録します。キャラクターの情報は含まれず、自分で送らない限りどこにも送信されません。
