- **名前を日本語で表示できます。** ようこそウィンドウと設定に新しい選択肢が加わり、NPC、クリーチャー、場所、アイテム、呪文、スキルの名前をカタカナで表示します。ツールチップ、ネームプレート、マップ、チャット、クエスト本文の中の名前が対象です。日本語を選ぶまでは英語のままです。名前にカーソルを合わせると、読みと英語の名前が出ます。
- **ツールチップを固定して読めます。** ツールチップが出ているときに Ctrl+F を押すと、その場に写しが残ります。日本語の単語を指すと読みと意味が出ます。アイテムと呪文の説明文に単語カードが付きました。Esc かもう一度キーを押すと閉じます。
- **チャットの補助が加わりました。** チャットの単語にカーソルを合わせると単語カードが出ます（LFM や WTS などの略語も）。「文」ボタンで定型文を開けます。定型文は英語で送られ、このアドオンを使う人には自分の言語で表示されます。行のアイコンでその行をコピーできます。
- **NPC が自分の声で話します。** 話し手が分からないクエストの行は、一人のナレーターの声で読まれていました。これからはその行を話す NPC の声で読み上げ、音声がまだない翻訳済みの行には `[音声なし / No Voice Yet]` と表示されます。
- **日本語になった範囲が広がりました。** Forever 1.60.1.71037 と 28 件の英語テキスト収集（NPC のセリフ 265 件、クエストのテキスト 325 件、新しいクエスト 129 件）、ほぼすべての呪文のツールチップ、フレンド、グループ検索、プロフェッション、ギルド、カレンダーのウィンドウです。
- **エラーが減りました。** 戦闘中にクリーチャーへカーソルを合わせてもエラーが大量に出なくなり、バッグのアイテム(Hearthstone など)がブロックされたときはアドオンのログに残るようになりました。
