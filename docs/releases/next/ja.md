- **名前を日本語で表示できます。** ようこそウィンドウと設定に新しい選択肢が加わり、NPC、クリーチャー、場所、アイテム、呪文、スキルの名前をカタカナで表示します。ツールチップ、ネームプレート、マップ、チャット、クエスト本文の中の名前が対象です。日本語を選ぶまでは英語のままです。ようこそ画面は機能を順に紹介する案内になりました。
- **知っている単語が分かります。** Shift+クリックで、単語に「未知・学習中・既知・無視」の状態を付けられます。クエスト、NPC の会話、本では、まだ知らない単語に下線が付き、次に覚えるとよい頻出の単語がハイライトされ、その文章をどのくらい知っているかが表示されます。`/wfj known` に Anki などの単語リストを貼り付けると、まとめて既知にできます。
- **ツールチップを固定して読めます。** ツールチップが出ているときに Ctrl+F を押すと、その場に写しが残ります。日本語の単語を指すと読みと意味が出ます。アイテムと呪文の説明文にも単語カードが付きました。
- **チャットの補助が加わりました。** チャットの単語にカーソルを合わせると単語カードが出ます（LFM や WTS などの略語も）。「文」ボタンで定型文を開けます。定型文は英語で送られ、このアドオンを使う人には自分の言語で表示されます。
- **Anki アドオンがカードを作ります。** 保存した単語が、ふりがな、スクリーンショット、文の音声付きのカードとしてパソコン版 Anki に届きます。GitHub のリリースから `WoWForeverJapanese.ankiaddon` を入手できます。
- **日本語の範囲が広がり、NPC が自分の声で話します。** Forever 1.60.1.71037 と 28 件の英語テキスト収集（NPC のセリフ 265 件、クエストのテキスト 325 件、新しいクエスト 129 件）、ほぼすべての呪文のツールチップ、さらに多くのウィンドウが日本語になりました。クエストの行は、その行を話す NPC の声で読み上げられます。
