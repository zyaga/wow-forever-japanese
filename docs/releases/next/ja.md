**追加**
- 英語を勉強中の方のための English first：メインの設定ページで「ゲームの文字」を *English first* にする（または `/wfj direction en`）と、アドオンが訳すところはすべてゲーム本来の英語のまま表示されます。キーを押している間だけ日本語になり、離すと英語に戻ります。これまでの使い方をそのまま逆にしたもので、初期設定はこれまでどおりです。日本語音声はキーを押している間だけ聞こえます。
- 英語の単語カード：English first では、クエスト本文、NPC の会話、本や手紙のページ、ウィンドウのラベルで英語の単語にマウスを合わせると、発音、その行の翻訳で使われている日本語の単語と読み方、その辞書形が表示されます。カードが付けられる単語のおよそ 9 割に付いています。名前、*a*、*the*、*is*、*have*、*of*、*to* のような単語や、ゲームが絵や見出し付きで組んでいるページには付きません。
- 英語の単語の保存と学習：English first では、保存のクリックで英語の単語を、発音、日本語の単語、英語の文、日本語の文と一緒に保存します。学習カードは英語の単語と文を表に、日本語を裏に出します。書き出した一覧にも入ります。
- 使い方を聞くようこそ画面：「日本語を学ぶ」「英語を学ぶ」「日本語で遊ぶ」から 1 つ選んで「決定」を押すと、ゲームの文字、単語カード、学習タブがそれに合わせて設定され、始めるために知っておくことが表示されます。すでにアドオンを使っている方も含め、全員に 1 回だけ表示され、「決定」を押すまで何も変わりません。設定ページの上、「情報とヘルプ」ページ、`/wfj intro` からいつでも開けます。

**変更**
- 設定ページにゆとりができました。必要なページはスクロールでき、セクションの間が空き、説明が短くなりました。「情報とヘルプ」以外のページに「初期設定に戻す」ボタンがあり（クリックして 5 秒以内にもう一度クリック）、そのページの設定だけを戻します。バージョン、メモリ、データの数は「情報とヘルプ」ページに移りました。
- 音声の設定と音声パネルの設定がひとつの「音声」ページにまとまりました。
- キーの設定の名前が「押している間はもう一方の言語を表示」になりました。「ゲームの文字」に合わせて英語か日本語を表示するためです。
- English Collector のページは送り方を 1 行で説明し、手順は送信ウィンドウに表示されるようになりました。
- クエスト名はどこでもゲームの英語のままになりました（クエスト一覧、トラッカー、クエストログ、クエストウィンドウ、NPC との会話のクエストの行、Dialogue UI のウィンドウ、ツールチップ、システムメッセージ）。クエスト名は人や場所の名前と同じく、攻略サイトで調べたり、チャットでリンクしたり、パーティーの仲間に伝えたりするための名前です。クエストの本文、目標、説明はこれまでどおり日本語です。
- 音声は、英語の名前を画面の英語に合った日本語の音で読むようになりました。Black Dragonflight は訳さずに「ブラック・ドラゴンフライト」、Tiger は「タイガー」です。画面の名前はこれまでどおり英語です。
- 音声をすべて作り直しました。それぞれの NPC の声が行ごとに安定し、よく読み間違えていた言葉（冒険者、金（かね）や獣（けもの）のような 1 字の言葉、スペースの直後の言葉）を正しく読みます。
- 新しいアイコン：「字」が明るい赤の円に金色の太い筆文字になりました。ミニマップボタンは金の二重の縁なしで、輪の中央に収まります。

**修正**
- Dialogue UI で、アイテムのツールチップの日本語の効果の行（使用、装備、命中時、フレーバーの一文）が空の四角で表示されなくなりました。
- 自分のキャラクターのエラーの一言（射程外、マナ不足）がゲームの「エラーの音声」設定に従うようになりました。オンなら日本語が聞こえ、オフなら何も聞こえません。アドオンがこの設定を自分でオフにすることはなくなり、以前のバージョンがオフにしていた場合は 1 回だけオンに戻します。
- Ellesmere UI で、それが作り直すゲームのウィンドウに日本語の代わりに空の四角が出ないようにできます。Ellesmere UI のフォント設定（`/eui`、Fonts）で Global Font に **WoW Forever Japanese** を選んでください。Ellesmere UI 自身のウィンドウは英語のままで、チャットウィンドウには対応していません。日本語でチャットするには、アドオン一覧でその Chat モジュールをオフにしてください。
- Dialogue UI で、クエスト名の上のタグ（ダンジョン、レイド）が空の四角で表示されなくなりました。
- Legacy ツリーのタレントのツールチップが、タレントウィンドウを開く前でも日本語の行を表示します。ツリーの名前は英語のままです。
- クエストトラッカーの右クリックメニューからのクエストの共有や、戦闘中の世界地図のクエストマーカーで、このアドオンの名前が出る「アクションがブロックされました」が出なくなりました。戦闘中のクエストの共有は、ゲーム自体ができない操作です。
- 単語カードがなかったクエスト、NPC、本の約 60 行の単語にもカードが付きました。
- 大将軍（warlord）の単語カードの読みが、それを使う 3 つのクエストで「たいしょうぐん」になりました。
- Legacy ボードのチャレンジや実績ウィンドウの実績をクリックしても、名前と説明が英語に変わらなくなりました。
