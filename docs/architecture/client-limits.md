# Client limits

> What the World of Warcraft: Forever client keeps from addons, what that means for the addon, and where each fact comes from ([ADR-051](../adr/051-hidden-tooltip-passes-translate-the-clients-data.md) records the decision behind the tooltip rows). The client marks some values **secret**: an addon may hold one, pass it on and put it on the screen, but may not read, compare, concatenate or index with it (`issecretvalue` tells one apart; `type()` still answers). Every claim here cites the client's own files, read from the 1.60.1.70170 extract (`blizzard_apidocumentationgenerated`), or an in-game trace (`/wfj debug tooltip`).

## Rules these limits set

- A hidden value is never compared, concatenated, measured or used as a key. A FontString whose text is secret is never read back; a record that would compare it is let go first (`Render.discard`). A FontString whose font is secret keeps its English: no font is set on it.
- Nothing of this addon writes text or a font into a Blizzard FontString that Blizzard measures on the way to a protected call, and nothing of this addon runs inside such a pass (a post-hook on a function the pass calls). A surface like that is followed from the addon's own frame (`UI/TextWatch`) or left English.
- No addon initializer is added to a menu whose entries check a protected call while the menu is built (the unit right-click menus). A static test fails on any shipped Lua that names a unit menu tag or an Edit Mode frame (`tests/python/test_protected_paths.py`); `UI/TaintWatch` only reads, so it may name them.
- A frame's regions and children are listed only through `UI/Frames` (`Frames.regions`, `Frames.children`), never with a bare `:GetRegions()` or `:GetChildren()`. A static test fails on any such call in shipped Lua outside `UI/Frames.lua` (`tests/python/test_frame_walk.py`).
- Addon code never calls a Blizzard function that opens a Blizzard window and writes its fields (`QuestMapFrame_OpenToQuestDetails`). The player's own click opens it, or the addon shows its own window.
- Addon code never calls a Blizzard frame method that fires the frame's scripts on a quest surface (`UpdateScrollChildRect` on the quest log's details pane, the quest popup or the quest window). A static test fails on any `UpdateScrollChildRect` in shipped Lua outside `UI/ItemText.lua` and `UI/Tutorial.lua` (`tests/python/test_protected_paths.py`).
- `taintLog` is never turned on. A blocked action is traced with the problem log ([Diagnostics](../systems/diagnostics.md#tracing-a-blocked-action)).
- Nothing is learnt or remembered to work around a limit. A surface the client hides is left in the client's English until the client shows it, and shows Japanese again on its own then.
- A new limit, or one that lifts (the client's rules move between builds), is found by the trace: `/wfj debug tooltip on`, the hover, `/wfj debug tooltip`. The entry of a hidden pass names every data row, the row map and the duration object.
