# What the addon does with each kind of tooltip line the client tags (Enum.TooltipDataLineType;
# the list is pipeline/tooltip_line_kinds_inventory.txt, from the client's own API documentation).
# `<Kind>  # <decision>`, one per kind. A decision is one of:
#   translated: <UI/Module>; keys: <KEY> <KEY> ...; <why>   the module writes the line from these dictionary keys
#   translated: <UI/Module>; data: <what>; <why>            the module writes it from the data records (quest, spell,
#                                                          item, a client-table family), not from fixed keys
#   english: <reason>                                      the line stays as the client wrote it, and why
# tests/python/test_tooltip_line_kinds.py fails when an inventoried kind has no decision, a decision names a kind the
# client does not have, a named key is not a shipped dictionary key, or a UI/TooltipUnit key is not in its key list.
# Re-check every decision when a new kind appears on a client build.
