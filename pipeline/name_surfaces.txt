# Every widget or text slot of the Forever client that holds a name, and what the addon does with it while
# Japanese names are on. One line each, tab-separated:
#   <module>  <widget or slot>  <mark>  <note>
# Marks:
#   japanese            shows the name's Japanese (UI/NameLabels, the policy layer's names step, or a value kind)
#   todo                a game name the addon does not show in Japanese yet; tests/python/test_name_surfaces.py
#                       fails while any line carries it
#   english <reason>    stays as the client writes it, for one of these reasons:
#     player-typed        a player's, guild's, pet's, channel's, macro's or set's name: not a game name
#     text-box            a box the player types in, or a search box: it needs the client's English
#     secret              the client hides the value from addons (a unit's name in combat in an instance)
#     protected           the client measures the widget on the way to a protected action: text written there
#                         taints that action, and it is then blocked in combat (docs/architecture/client-limits.md)
#     not-a-game-name     a number, a date, a dictionary word, prose, or a kind the name list does not hold
#     client-drawn        the client draws it in the game world itself: there is no widget an addon can write to
# A module's NEVER_TOUCH widget must have a line here (the test reads the modules). A name with no line in the name
# list stays English whatever its mark says.
